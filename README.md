# Pygame Template

A minimal and reusable template for building games with **Python and Pygame**.

## Features

* 900 × 600 game window
* 60 FPS game loop
* Basic event handling
* Close the game with `ESC`
* Clean starting point for new Pygame projects

## Requirements

* Python 3
* Pygame

Install Pygame:

```bash
pip install pygame
```

## Run

```bash
python main.py
```

## Controls

| Key   | Action |
| ----- | ------ |
| `ESC` | Exit   |
